# Photo Cull · 照片评级分类

一个在浏览器里运行的照片筛选工具：先自动给照片打分，再用键盘快速打星、标记、分类，最后把照片整理进文件夹。

只有一个 `index.html` 文件，不用安装，也不需要服务器。照片全部在你自己的电脑上处理，不会上传到任何地方。

> English: a single-file, in-browser photo culling tool. It scores sharpness and exposure, groups bursts by capture time and flags the sharpest frame in each burst. You rate with the keyboard, tag photos with categories, and it moves them into folders (with undo). Everything runs locally in Chrome or Edge via the File System Access API.

## 功能

- **自动打分**
  - 计算每张照片的清晰度：把画面分成 10×10 小块，取最清楚那块的拉普拉斯方差。所以主体清楚、背景虚化的照片也能得到高分。
  - 计算亮度和过曝比例。
  - 按 EXIF 拍摄时间把连拍归成一组，标出每组最清楚的一张（**最佳**）。
  - 提示**模糊**、**欠曝**、**过曝**的照片。
- **手动评级**
  - 键盘 `1`–`5` 打星，`X` 标记待删除，`T` 设置分类，`Ctrl+Z` 撤销。
  - 大图模式下可以放大到 100% 检查对焦。
- **分类建议**
  - 给一张照片设置分类（`T`），默认套用到整组连拍。
  - 下一组照片如果拍摄时间相隔不到 10 分钟，会建议沿用上一组的分类（虚线标签），按 `A` 接受并跳到下一张未分类的照片。
- **AI 识别（可选，免费，本机运行）**：点"AI 识别"→"开始识别"，每组连拍只识别最清楚的一张。
  - **先分大类**：用物体检测模型找鸟，再用 BioCLIP 2 核对一遍。有鸟就归为"鸟"，没有鸟再判断兽类、爬行类、两栖类、昆虫、植物等。
  - **鸟再识别到种**：把鸟裁出来，和全球约 1.08 万种鸟比对，给出 3 个备选，中文名、英文名都有。"拍摄地区"选"南部非洲"时，会优先考虑南非鸟类名录里的约 860 种。
  - **越用越准**：你确认过的组会被记住，后面遇到很像的鸟（相似度 ≥ 85%），会把你用过的分类名排进备选。
  - **逐组确认**（`R`）：识别完自动进入。每组显示大图和 3 个备选，按 `1` `2` `3` 选择，`4` 是"只标为鸟，暂不定种"；都不对就按 `T` 手动输入；空格跳过，`Ctrl+Z` 撤销。选中的分类会套用到整组连拍。
  - 整理文件时，认出是鸟的照片默认放进 `鸟/物种名` 子文件夹（可以关掉）。
  - 第一次使用要下载模型：有显卡加速（WebGPU）时约 650 MB，速度大约每组 1–2 秒；没有显卡加速时用 CPU 版（约 350 MB），每组 5 秒以上。照片不会上传。国内可以在对话框里选 hf-mirror.com 镜像。
  - 模型下载后保存在浏览器的私有存储里，下次不用重新下载。想删掉的话，在浏览器设置里清除这个网站的数据即可。
  - 在作者的 163 张南非鸟类照片上测试（选"南部非洲"）：鸟全部找出来了，50 张非鸟照片里有 1 张（鲸）被当成鸟；第一个备选正确 84%，三个备选里有正确答案 93%。动物园里的外地鸟、远处很小的鸟、相近的种（几种花蜜鸟、鸬鹚）最容易认错。
  - 没有鸟的照片只给大类，风景、废片等没有专门的类别，可能会被猜成植物或兽类。
  - 双击本地 `index.html` 打开时，浏览器不允许读取旁边的 `data/` 文件，工具会改从 GitHub 上已发布的副本（jsDelivr）读取，所以要先把 `data/` 推送到 GitHub。用 GitHub Pages 网址打开没有这个问题。
- **一键初筛**
  - 把模糊或曝光有问题的照片批量标记为待删除。
  - 或者每组连拍只保留最佳的一张。
  - 两种方式都可以撤销。
- **整理文件**
  - 有分类的照片移到以分类命名的子文件夹。
  - 待删除的照片移到 `_待删除` 文件夹。**不会真正删除任何文件**，确认没问题后再自己删掉。
  - 整理记录保存在 `photo-cull-moves.json`，可以一键撤销。
- **自动保存**
  - 评级、分类和打分结果保存在照片文件夹里的 `photo-cull.json`。
  - 下次打开同一个文件夹会直接接着用，不用重新分析。
- **导出 CSV**：包含文件名、拍摄时间、清晰度、星级、分类等，可以用 Excel 打开。

## 使用方法

1. 用电脑版 **Chrome** 或 **Edge** 打开 `index.html`。双击本地文件或用 GitHub Pages 的网址都可以。
2. 点 **打开文件夹**，选择照片所在的文件夹，并允许浏览器“查看和编辑”这个文件夹。
3. 等进度条跑完。第一次分析大约每秒 5 张，2000 张照片大约要 7 分钟。之后再打开同一个文件夹会直接读取保存的结果。
4. 浏览、打星、分类，最后点 **整理文件**。

支持 JPG / PNG / WebP，默认包含子文件夹，可以在设置里关闭。RAW 和 HEIC 暂不支持。

Firefox 和 Safari 不支持直接写入文件夹，只能用只读方式打开：可以打分和导出 CSV，但不能自动保存，也不能整理文件。

## 快捷键

| 按键 | 作用 |
|---|---|
| `1`–`5` | 打 1–5 星 |
| `0` | 清除星级和待删除标记 |
| `X` / `Delete` | 标记 / 取消待删除 |
| `T` | 设置分类，默认套用到整组连拍 |
| `A` | 接受分类建议（虚线标签），并跳到下一张未分类的照片 |
| `R` | 逐组确认：每组给出 AI 的 3 个备选，数字键选择，`T` 手动输入 |
| `G` | 选中整组连拍 |
| `B` | 跳到本组最佳 |
| 方向键 | 移动，按住 `Shift` 扩大选择 |
| `Enter` / `Space` | 大图查看，`Z` 或单击图片放大到 100% |
| `Ctrl+A` | 全选当前显示的照片 |
| `Ctrl+Z` | 撤销 |
| `Esc` | 关闭大图 / 取消选择 |

鼠标：单击选择，`Ctrl`+单击多选，`Shift`+单击连选，双击看大图。

## 设置

| 设置 | 默认值 | 说明 |
|---|---|---|
| 连拍间隔 | 2 秒 | 拍摄时间相差不超过这个值的照片算同一组 |
| 模糊判定（相对） | 50% | 清晰度低于同组最清楚那张的 50%，算模糊 |
| 模糊判定（全局） | 10% | 清晰度排在整个文件夹最后 10%，也算模糊 |

清晰度分数是相对的：同一个文件夹里的照片互相比较，不同文件夹之间的分数不能直接比。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，把这个文件夹里的文件上传上去。
2. 进入仓库的 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
3. 稍等一会儿，就能通过 `https://<用户名>.github.io/<仓库名>/` 在线使用。照片仍然只在本地处理。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 整个工具（界面、分析、整理都在这一个文件里） |
| `data/birds.bin`、`data/birds.json` | AI 识别用的鸟类数据：10,805 种鸟的 BioCLIP 2 文本向量、中英文名、是否在南非名录里 |
| `data/refs.bin`、`data/refs.json` | AI 识别用的非鸟参照：约 2.2 万个常见兽类、爬行类、昆虫、植物等物种的向量，用来判断"是不是鸟"和大类 |
| `photo-cull.json` | 自动生成在照片文件夹里，保存评级和打分结果 |
| `photo-cull-moves.json` | 自动生成在照片文件夹里，保存上次整理的记录，用于撤销 |

## 数据和模型来源

AI 识别用到的模型和数据都是公开的，运行时从 Hugging Face 下载，或者已经放在 `data/` 里：

- **BioCLIP 2**（Imageomics Institute，MIT 许可证）：图像模型使用 [Lumilio-Photos/bioclip-2](https://huggingface.co/Lumilio-Photos/bioclip-2) 的 fp16 ONNX 版，没有显卡加速时用 [rickyho/bioclip2-onnx](https://huggingface.co/rickyho/bioclip2-onnx) 的 int8 版。`data/` 里的物种向量取自 rickyho/bioclip2-onnx 预先算好的 TreeOfLife 物种文本向量。这两个 ONNX 版本都是第三方转换的，以后如果被删除，AI 识别就无法使用。
- **D-FINE 物体检测模型**：[onnx-community/dfine_s_coco-ONNX](https://huggingface.co/onnx-community/dfine_s_coco-ONNX)，用来找出照片里的鸟。
- **鸟类中英文名**：IOC World Bird List v15.2（Gill, F., Donsker, D. & Rasmussen, P. 编，[worldbirdnames.org](https://www.worldbirdnames.org/)）。
- **南非鸟类名录**：取自英文维基百科 "List of birds of South Africa"。
- 运行库：[Transformers.js](https://github.com/huggingface/transformers.js) 3.8.1，从 jsDelivr 或 unpkg 加载。
