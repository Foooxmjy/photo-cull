# Photo Cull · 照片评级分类

一个在浏览器里运行的照片筛选工具：先自动给照片打分，再用键盘快速打星、标记、分类，最后把照片整理进文件夹。

只有一个 `index.html` 文件，不用安装，也不需要服务器。照片全部在你自己的电脑上处理，不会上传到任何地方。

> English: a single-file, in-browser photo culling tool. It scores sharpness and exposure, groups bursts by capture time and flags the sharpest frame in each burst. You rate with the keyboard, tag photos with categories, and it moves them into folders (with undo). Everything runs locally in Chrome or Edge via the File System Access API.

## 功能

- **自动打分**
  - 计算每张照片的清晰度：把画面分成 10×10 小块，取最清楚那块的拉普拉斯方差。所以主体清楚、背景虚化的照片也能得到高分。
  - 计算亮度和过曝比例。
  - 按 EXIF 拍摄时间把连拍归成一组，标出每组最清楚的一张（**最佳**）。
  - 提示**模糊**、**欠曝**、**过曝**的照片。
- **手动评级**
  - 键盘 `1`–`5` 打星，`X` 标记待删除，`T` 设置分类，`Ctrl+Z` 撤销。
  - 大图模式下可以放大到 100% 检查对焦。
- **一键初筛**
  - 把模糊或曝光有问题的照片批量标记为待删除。
  - 或者每组连拍只保留最佳的一张。
  - 两种方式都可以撤销。
- **整理文件**
  - 有分类的照片移到以分类命名的子文件夹。
  - 待删除的照片移到 `_待删除` 文件夹。**不会真正删除任何文件**，确认没问题后再自己删掉。
  - 整理记录保存在 `photo-cull-moves.json`，可以一键撤销。
- **自动保存**
  - 评级、分类和打分结果保存在照片文件夹里的 `photo-cull.json`。
  - 下次打开同一个文件夹会直接接着用，不用重新分析。
- **导出 CSV**：包含文件名、拍摄时间、清晰度、星级、分类等，可以用 Excel 打开。

## 使用方法

1. 用电脑版 **Chrome** 或 **Edge** 打开 `index.html`。双击本地文件或用 GitHub Pages 的网址都可以。
2. 点 **打开文件夹**，选择照片所在的文件夹，并允许浏览器“查看和编辑”这个文件夹。
3. 等进度条跑完。第一次分析大约每秒 5 张，2000 张照片大约要 7 分钟。之后再打开同一个文件夹会直接读取保存的结果。
4. 浏览、打星、分类，最后点 **整理文件**。

支持 JPG / PNG / WebP，默认包含子文件夹，可以在设置里关闭。RAW 和 HEIC 暂不支持。

Firefox 和 Safari 不支持直接写入文件夹，只能用只读方式打开：可以打分和导出 CSV，但不能自动保存，也不能整理文件。

## 快捷键

| 按键 | 作用 |
|---|---|
| `1`–`5` | 打 1–5 星 |
| `0` | 清除星级和待删除标记 |
| `X` / `Delete` | 标记 / 取消待删除 |
| `T` | 设置分类 |
| `G` | 选中整组连拍 |
| `B` | 跳到本组最佳 |
| 方向键 | 移动，按住 `Shift` 扩大选择 |
| `Enter` / `Space` | 大图查看，`Z` 或单击图片放大到 100% |
| `Ctrl+A` | 全选当前显示的照片 |
| `Ctrl+Z` | 撤销 |
| `Esc` | 关闭大图 / 取消选择 |

鼠标：单击选择，`Ctrl`+单击多选，`Shift`+单击连选，双击看大图。

## 设置

| 设置 | 默认值 | 说明 |
|---|---|---|
| 连拍间隔 | 2 秒 | 拍摄时间相差不超过这个值的照片算同一组 |
| 模糊判定（相对） | 50% | 清晰度低于同组最清楚那张的 50%，算模糊 |
| 模糊判定（全局） | 10% | 清晰度排在整个文件夹最后 10%，也算模糊 |

清晰度分数是相对的：同一个文件夹里的照片互相比较，不同文件夹之间的分数不能直接比。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，把这个文件夹里的文件上传上去。
2. 进入仓库的 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
3. 稍等一会儿，就能通过 `https://<用户名>.github.io/<仓库名>/` 在线使用。照片仍然只在本地处理。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 整个工具（界面、分析、整理都在这一个文件里） |
| `photo-cull.json` | 自动生成在照片文件夹里，保存评级和打分结果 |
| `photo-cull-moves.json` | 自动生成在照片文件夹里，保存上次整理的记录，用于撤销 |
